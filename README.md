# Тихонов Клочкова онлайн мморпг 3 в ряд

## Описание проекта

MMORPG с элементами "три в ряд" где игроки могут соревноваться друг с другом или с ботами, получая награды в виде предметов различного качества.

## Особенности:
- Игровой режим "три в ряд"
- Персонажи с экипировкой
- Рейтинговая система
- Админ-панель
- Использование Kafka для обработки матчей
- Встроенный таймер матча (45 секунд)
